# Pure_Strategy_Game

# Description
This project is a course project for the Introduction to programming course.
It implements a turn-based game based on the concept of GOPS (Game of Pure Strategy), where players make decisions according to predefined rules. The project demonstrates object-oriented programming, file handling, and basic game logic in C++.

---

# Features
- Turn-based game logic
- Player and opponent management
- Tracking and storing game statistics
- Support for multiple user profiles
- Randomized game behavior using seed-based shuffling
- Reading and writing data from/to text files

---

# How to Use
1. Compile all `.cpp` files together using a C++ compiler.
2. Run the executable.
3. Follow the on-screen instructions to start a game.
4. The program automatically manages players, opponents, and statistics.

---

# Project Structure
- `main.cpp` - Program entry point and initialization
- `Game` - Core game logic
- `Player` - Player behavior and actions
- `Deck` - Card/deck management
- `UserProfile / UserProfiles` - User profile handling
- `UserManager` - User management logic
- `Statistics / OpponentStatistics` - Opponent statistics
- `Seed` - Seed loading and saving
